# Onboarding controllato Astralis 3

Configurare HubRoot e TargetDir espliciti. In questa versione Apply e consentito soltanto sotto una staging temporanea marcata; aggiornamento reale dei progetti escluso.

Eseguire prima Check con --source, --target, --mode check e --staging-root per export; con -HubRoot, -TargetDir, -Mode check e -StagingRoot per bootstrap.

I template sono bozze; il bootstrap renderizza HUB e conoscenza locale senza modificare le fonti.
